# Modifiche al database

Il database del progetto Supabase bingo-game-awards è aggiornato fino alla v8 (24/11/2026).
Le modifiche si applicano a mano (da Claude o dall'editor SQL di Supabase), non più da GitHub.

- v1: `tabelle-bingo-v1.sql`
- v2-v8: `migrations/`, in ordine di numero
- Per una nuova modifica: un file nuovo con numero più alto. Mai cambiare un file già applicato.
